# rouletting-support

Privacy policy and support pages for [Rouletting!](https://github.com/Hideaki-Nozawa-SIG/RouletteApp), published via GitHub Pages.

- `index.html` — landing page
- `privacy.html` — Privacy Policy (used as the App Store Connect "Privacy Policy URL")
- `support.html` — Support page (used as the App Store Connect "Support URL")

Source content lives in the main app repo at `docs/store-listings.md`; this repo only holds the rendered public pages, since GitHub Pages requires the repo serving them to be public and the app repo stays private.
